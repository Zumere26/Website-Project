Baked with love, decorated like royalty

The Royal Whisk by Princess is a home bakery run by Princess Damane, creating custom cakes, cupcakes and dessert platters for birthdays, weddings and every celebration in between. Every order is made fresh, from scratch, using quality ingredients and a lot of care.
